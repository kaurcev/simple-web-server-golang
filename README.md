# simple-web-server-golang

Простой HTTP-сервер на Go для раздачи статики из папки `./public`. Написан в рамках изучения языка, чтобы разобраться с пакетами, интерфейсами и middleware.

## Что внутри
- Статика отдается через стандартный `http.FileServer`.
- Ошибки 404 перехватываются вручную: перед отдачей файла код проверяет его наличие на диске через `os.Stat`. Если файла нет — отдается кастомная HTML-заглушка.
- Логирование запросов вынесено в отдельный middleware. Написана минимальная обертка над `http.ResponseWriter`, чтобы вытягивать статус-коды ответов прямо в консоль.

## Логи в рантайме
Из-за компиляции в бинарник и кэширования файлов самой операционной системой, скорость обработки запросов получается такой:
- Первый запрос (чтение с диска): меньше 1 миллисекунды (~500–900 µs).
- Повторные запросы (из кэша ОС): мгновенно (`0s` в логах, так как выполнение занимает наносекунды).

## Структура проекта
- `cmd/server/main.go` — запуск сервера и связывание модулей.
- `internal/filesystem/` — проверка файлов на диске.
- `internal/delivery/http/` — хендлер для 404 и middleware для логирования.
- `public/` — папка с HTML/CSS/JS
